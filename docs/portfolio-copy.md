## LinkedIn project description

I developed the Global Economic Intelligence Agent from a FastAPI/Streamlit prototype into a [deployed Cloudflare research workspace](https://global-economic-intelligence.nicholai-gay.workers.dev). Visitors can explore annual World Bank indicators for five economies, compare countries on common periods, ask supported questions, inspect indicator and dated report sources, and export the exact displayed assessment as a PDF. The public release uses deterministic calculations and a clearly labelled saved demonstration; it makes no paid model calls. Preview and production deployments were smoke-tested with live World Bank data.
