# 60–90 second demonstration script

**0–10 seconds — framing.** “This workspace answers a practical question: what do the numbers say about an economy, and which sources support that reading?” Show the dated Saved demo label.

**10–25 seconds — overview.** Select the Netherlands. Point to GDP growth, inflation and unemployment. Read the observation years aloud: the first two are 2024, unemployment is 2025. Open the source link. Mention that Live data retrieves historical World Bank series when available.

**25–42 seconds — comparison.** Open Compare. Keep Netherlands, Germany and France selected. Show the common 2024 GDP-growth period, the table, and the shareable URL. Explain that missing years remain blank.

**42–68 seconds — analyst.** Open Ask the analyst, choose the suggested general question and run it. Follow a finding's indicator citation. Show the dated ECB excerpt as separate report context and the limitations about the snapshot.

**68–85 seconds — export.** Click Export this briefing. Show the PDF title, question, same findings, source IDs and dates. Close by saying that export uses the on-screen analysis object and makes no paid model call.

For a live demo, switch to Live data only after confirming World Bank access at the venue; the saved demonstration is the reliable default.
